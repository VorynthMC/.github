## ⚜️ Le royaume

**VORYNTH** réunit l'ambiance d'un MMORPG et la liberté du survival Minecraft. Construisez, explorez, progressez et écrivez votre propre histoire aux côtés d'une communauté d'aventuriers.

| | |
|---|---|
| ⚔️ **Donjons** | Trois difficultés : Normal, Hard et Épique |
| 🛡️ **Guildes** | Contrats, alliances et vie communautaire |
| 🐉 **Dragons** | Découvrez, apprivoisez et faites évoluer votre compagnon |
| 💰 **Économie** | Plusieurs monnaies, banques et Hôtel des Ventes |
| 🔨 **Métiers** | Artisanat, commerce et productions spécialisées |
| 🏡 **Construction** | Bâtissez librement et protégez votre base grâce aux claims |

## 🚀 Comment nous rejoindre ?

1. 💬 Rejoins notre **[Discord](https://discord.gg/VOTRE_LIEN)**
2. 📜 Lis le règlement et choisis tes rôles
3. 🎮 Prépare **Minecraft Java Edition 1.21.1** avec un compte Microsoft
4. 📥 Installe le **launcher officiel** dès sa sortie
5. ⚔️ Entre dans le royaume !

> 🔐 **Phase actuelle :** VORYNTH est en développement. L'accès aux phases de test se fait **sur invitation**. Les dates de bêta et d'ouverture seront annoncées sur Discord.

## 👑 Boutique

Le serveur est **gratuit**. Une boutique facultative proposera des grades et des cosmétiques.
**Aucun pay-to-win** : les avantages premium sont purement cosmétiques.

## 📱 Et Bedrock ?

Une version **Bedrock** est en développement, avec pour objectif une sortie approximativement en même temps que Java (prévisionnel, selon les tests techniques).
